# Memory Machine

Memory Machine is the working name for a public-facing knowledge project.
It is intended to hold a reviewed selection of notes, cards, and other
materials from the private Warehouse memory system.

This repository is an initial shell. Its name, structure, and publishing
workflow remain open to refinement. No Warehouse records have been copied
here, and no website or publication workflow has been configured.

Before copying any material into a public repository, review the exact files,
including their content, names, metadata, links, and assets. The public
repository must maintain its own history and must not contain Warehouse's
private Git history.
