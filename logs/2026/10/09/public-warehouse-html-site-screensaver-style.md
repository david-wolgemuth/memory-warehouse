# Public Warehouse HTML site should share the screensaver's style

On 2026-10-09, after seeing the screensaver still (unavailable in this public edition),
David directed that a future public website made of HTML pages should share
the completed screensaver's visual style. He framed this as a note for later.

Interpret this as a design direction for a future public HTML version of
Warehouse: use the completed terminal screensaver as its visual reference.
The current preview and screensaver source (unavailable in this public edition)
show a dark background, a contrasting title band, colored Markdown headings,
and a compact status/control area. Those are current observations, not a
separate commitment to freeze exact colors or terminal-specific controls.

This note does not request building or publishing the website now. The
[public projection review](../../../../cards/private-source-public-projection-security-model.md)
still governs which Warehouse records may be placed on a public site.
