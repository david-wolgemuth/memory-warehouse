# Possible six-panel desktop layout for the public Warehouse site

On 2026-10-09, David added a possible layout for the future public HTML site:
when viewed full screen on a desktop, it could show a 3×2 arrangement of six
displays, each roughly the physical dimensions of a mobile phone, with each
display changing every 12 seconds. This follows his [direction to share the
terminal screensaver's visual style](./public-warehouse-html-site-screensaver-style.md).

I interpret 3×2 as three columns and two rows of portrait panels. The physical
phone-size description is an approximate visual target, not a measured CSS
specification. David did not specify whether the six panels change together or
on staggered schedules; keep that choice open when designing the interaction.

The wording “could have” makes this a proposed layout for a future build,
scoped to full-screen desktop viewing, rather than a requirement for the
terminal screensaver or for smaller browser windows.
