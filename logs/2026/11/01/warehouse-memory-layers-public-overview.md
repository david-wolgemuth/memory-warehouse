# Warehouse memory layers

Warehouse is a local-first memory system shared by a person and their agents.
Its Markdown records are the source of truth. Dated logs capture observations,
ideas, and evidence; small cards state reusable claims and link to evidence;
skills contain repeatable procedures; and indexes provide curated navigation.

A separate public projection contains selected, reviewed records. It is not a
complete copy of the private source repository.

This overview summarizes Warehouse's README and its publication policy as of
2026-11-01.
