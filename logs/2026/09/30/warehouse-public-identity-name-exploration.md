# Warehouse name may not fit its emerging public identity

## User direction

David is considering a rebrand. Warehouse suited the original storage concept,
but feels less fitting as the project moves toward a public, AI-assisted blog or
shared account of thought and memory. He mentioned a “cyborg brain” direction
as a possible metaphor, without choosing a name or authorizing a rename.

## Context

The name of the private source repository and the title of a future public
publication can be decided separately. The public title can be explored before
changing file paths, repository names, or links. The 2026-09-10 design log
records why Warehouse was originally chosen: a metaphor for local-first memory
storage. See Warehouse memory-system design (unavailable in this public edition).
