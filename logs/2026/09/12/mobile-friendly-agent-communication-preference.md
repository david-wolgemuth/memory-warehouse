# David prefers short, linked, mobile-friendly agent replies

## Direction from David

David reads many agent replies on a mobile device, where scrolling back through
chat history is inconvenient. Agent replies should therefore be short and
well-formatted, while the durable work record can be substantially more
detailed in Warehouse logs. When a response relies on or creates a log, the
response should include a direct link to that log so David can read the detail
there.

David's preference is for quick action-oriented answers and small bullet lists
where they clarify multiple points. The prose should be straightforward and
not needlessly jargon-heavy. This does not mean reducing the vocabulary to an
overly basic level: use normal technical language when it is accurate and
useful, but choose familiar, plain wording when possible.

## Log-maintenance guidance from David

Logs do not need polished prose. They may be rough, detailed, and
stream-of-consciousness if that is the best way to preserve the work and its
context.

For minor follow-up thoughts or small updates to the same topic, appending a
brief timestamped note is appropriate. When the topic changes or the new
material would require embedded edits and reworking of the old account, create
a new topic-named dated log instead. Do not spend effort reshaping a historical
log to make it read like a current document.

If a log begins to collect many additions and revisions because it is becoming
a stable, reusable conclusion, it is likely ready to become a card. Cards are
the place for the clean durable claim; the logs remain the historical evidence.

## Interpretation and implementation

This is a repeatable operating preference, so it belongs in `AGENTS.md` (unavailable in this public edition) as
well as this event log. The guidance was written as practical constraints:

- Lead replies with the outcome or immediate action.
- Keep chat concise; keep detail in a linked log.
- Use bullets only when they improve scanning.
- Prefer plain, precise wording and avoid decorative jargon.
- Create a fresh log for a substantial change in subject or understanding.
- Append only small factual corrections or timestamped continuations.
- Consider card promotion when repeated log maintenance signals a durable
  conclusion.
