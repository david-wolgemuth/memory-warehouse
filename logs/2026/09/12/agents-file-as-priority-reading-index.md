# AGENTS.md is a priority-ordered index of durable operating cards

Historical note: the startup-reading rule described here has since changed;
the current `AGENTS.md` (unavailable in this public edition) specifies the current scope of required reading.

David directed that `AGENTS.md` (unavailable in this public edition) should function primarily as an index rather
than a long policy document. It should use concise, self-explanatory bullets
organized by subject and priority, with each bullet linking to the card that
contains the fuller rule and rationale.

The final operating section must require agents to read all cards at session
start and to explicitly read every card in any indexed subject that relates to
the current task before taking action. This maintains a short entry point while
making the detailed, evidence-linked policy easy to find and revise.
