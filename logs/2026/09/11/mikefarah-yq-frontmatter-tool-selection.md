# Mike Farah yq is the intended frontmatter processor

## Note

- Earlier Warehouse references to `yq` point to Mike Farah's Go-based `yq`,
  which supports Markdown frontmatter directly. Debian's `yq` package is a
  different Python/jq wrapper and is not a substitute for this workflow.
- The official Linux AMD64 binary downloaded successfully from the project's
  GitHub latest-release URL. Global installation at `/usr/local/bin/yq` needs
  interactive `sudo` authentication, which was unavailable to this agent.
