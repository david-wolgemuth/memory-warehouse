# Visibility metadata separates private memory from public projection

## Note

- Warehouse remains the private source repository. Records are private unless
  their frontmatter explicitly declares `visibility: public`.
- A future public repository or export may select only public records. The
  marker is an affirmative review signal, not a claim that every repository
  commit is public.
- Initial public markers are limited to high-level project cards with public
  repositories and the governance notes defining this policy.
