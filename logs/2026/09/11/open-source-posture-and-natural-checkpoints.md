# Warehouse may be open source and uses natural checkpoint commits

## Note

- User wants to preserve the option of publishing Warehouse as an open-source
  repository. Agents should treat committed files as potentially public and
  avoid credentials, account/login identifiers, raw personal archives,
  personal profiles, browsing or message history, operational-security detail,
  and incidental sensitive data. Work material is limited to high-level,
  non-proprietary project context.
- At natural stopping points, agents may commit scoped Warehouse work and push
  `main` with concise commit messages. They must verify the staged diff and
  leave unrelated worktree changes out. A missing remote or rejected push is a
  blocker to report, not a reason to rewrite Git configuration.
