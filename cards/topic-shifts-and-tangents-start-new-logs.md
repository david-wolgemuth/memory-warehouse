# Topic shifts and tangents start new logs

When a subject change, tangent, or distinct later development merits a log,
create a new, small, subject-named log. Link to the earlier log when
the relationship helps future retrieval; do not continue an earlier file merely
because the same agent or conversation produced both events.

## Why it matters

Small notes preserve the context of each event and avoid turning a dated log
into a growing session journal. A direct link retains useful continuity without
mixing separate subjects into one record.

## Boundaries

This does not require splitting a coherent single-topic study because it is
long. An existing log may be extended only to correct an obvious error or add
an omitted factual detail. The append-only rule governing those limited edits
is separate; see Logs are append-only-ish (unavailable in this public edition).
