# Experimental agent design benefits from a bounded prototype portfolio

An autonomous design loop may maintain several explicitly bounded, playable
prototypes before promoting one to a canonical project. Each prototype needs a
distinct question, an observable artifact, an evaluation record, and a
retirement or promotion condition.

## Why it matters

Multiple small experiments prevent early generated coherence from becoming
unearned architectural commitment. Bounded status, budget, and expiry rules
preserve the value of comparison without turning exploration into an
ever-growing collection of abandoned code.

## Boundaries

This is not an endorsement of unlimited parallel projects or automatic merges.
Only evidence-backed, intentionally extracted mechanics should transfer from a
retired prototype into a promoted project.
