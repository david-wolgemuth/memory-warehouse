# Agent replies are mobile-friendly and link to detailed logs

Lead user-facing replies with the outcome or next action. Keep them short,
direct, plain-spoken, and easy to scan on a mobile device; use small lists only
when they clarify multiple points. Make the answer self-contained. When useful
detail belongs in an artifact, link it; do not create a duplicate log solely to
have something to link.

## Boundaries

Use normal technical vocabulary when it is the clearest term, but avoid
unnecessary jargon. Logs may be detailed and informal; use the separate
[topic-shift log boundary](./topic-shifts-and-tangents-start-new-logs.md) when
recording them.
