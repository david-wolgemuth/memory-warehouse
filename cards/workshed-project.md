# Workshed is portable personal developer infrastructure

Workshed is a personal system of scripts, notes, prompts, and small tools that
supports software-development work across code, tickets, conversations, and AI
sessions. Its local repository is (local source omitted); GitHub:
[david-wolgemuth/workshed](https://github.com/david-wolgemuth/workshed).

## Relationship to Warehouse

Workshed is active development and agent-work infrastructure: it gathers and
interprets changing work state, supports workflows and tool integrations, and
can manage external repositories such as Zettelkasten. Warehouse is a separate
Markdown-first memory repository. It records durable, evidence-linked context
for David and agents, deliberately without a built-in task tracker, runtime,
or orchestration layer.

Warehouse can preserve source-backed knowledge about Workshed, but it does not
replace Workshed's active work-state, workflow, or agent-session systems. No
current status, task ownership, or workflow execution is transferred into
Warehouse. Workshed remains the operational source for those functions.
