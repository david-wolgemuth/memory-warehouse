# Agent replies use helpful visuals for relationships and space

When explaining how parts of a project or world relate, or where things are
located, include a useful visual in the response when one makes the answer
easier to understand. David explicitly asked for more visuals in agent
responses and for an example in the RPG/worldbuilding discussion; see the
user-preference log (unavailable in this public edition).

Choose the form to match the question: diagram, map, timeline, comparison, or
state change. Keep it readable on mobile and briefly explain what the visual
shows. This is a contextual preference, not a demand for decorative visuals
in simple replies.

If an inline diagram displays as source code in the user's client, use a
visual format that renders there or provide a standalone image artifact;
the Paseo mobile observation (unavailable in this public edition)
shows that Mermaid rendering cannot be assumed from source support alone.
