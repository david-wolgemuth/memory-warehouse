# Substantive user directions require Warehouse capture

Every substantive user direction, decision, correction, or preference must be
preserved in the same turn in the smallest suitable Warehouse layer: usually a
dated log, and sometimes a card, skill, index, or operating-contract update.
Acknowledgment alone is not enough.

An ordinary question does not by itself require a same-turn log. Answer
promptly and create an artifact when useful material belongs outside the answer;
daily review can selectively capture findings from archived conversations later.

## Boundaries

Do not promote every direction to a card. Use logs for event evidence, cards
for durable reusable claims, skills for repeatable procedures, and indexes for
materially useful orientation.
