# DMSim is a setup-only prototype

DMSim currently creates a world, a three-to-six-member party, one defining
episode per companion, and three whole-party decisions. Normal scene play,
combat, NPC systems, autonomous party simulation, and backend synchronization
are outside the current runtime.
