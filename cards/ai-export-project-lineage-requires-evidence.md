# AI-export project lineage requires corroborating repository evidence

Conversation exports can establish project lineage when corroborated by a
working directory, repository identity, documentation, or commit history.
Similar themes alone are leads, not project identity; project relationships may
be many-to-many and should be captured as evidence-linked card connections.
