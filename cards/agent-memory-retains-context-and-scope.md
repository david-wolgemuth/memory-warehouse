# Agent memory retains the context and scope of a correction

When a user corrects an agent, preserve the source, triggering situation,
intended actor and object, rationale, and known boundaries. Promote it to a
broad rule only when the user explicitly sets that scope or repeated evidence
supports it.

## Why it matters

A context-free rule can turn a correct local preference into an incorrect
universal behavior. Scoped records let an agent apply durable direction without
inventing certainty or gathering irrelevant context.

## Boundaries

Explicit, broad user rules and verified invariants may use absolute language.
A contextual instruction should remain specific to its condition until later
evidence expands or revises it. A style draft that David is still evaluating is
a lead, not a Warehouse-wide contract.
