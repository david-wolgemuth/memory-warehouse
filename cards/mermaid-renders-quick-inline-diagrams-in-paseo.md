# Mermaid renders quick inline diagrams in Paseo

Use a `mermaid` Markdown fence for small flows, timelines and relationships
when an inline visual helps. Paseo has a dedicated Mermaid fence renderer;
David confirmed his mobile PWA displayed a diagram after restarting it.
The Paseo investigation (unavailable in this public edition)
and restart observation (unavailable in this public edition) support
this narrower claim.

Keep source in the relevant log when the diagram is part of durable Warehouse
work. If the client shows code instead of the diagram, use an image attachment
for the visual answer. Mermaid's automatic layout should not be treated as
geographic position.
